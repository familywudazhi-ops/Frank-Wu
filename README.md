# Trade Balance Live｜貿易平衡全民搶答

這是一款以「貿易差額對總體經濟的推波助瀾」為教材的 Kahoot 型全班同步搶答遊戲。

## 立即試玩

直接開啟 `index.html`：

- 選擇「教師主持」→「先玩單機示範」：在同一個瀏覽器檢視完整遊戲流程。
- 選擇「學生加入」→「單機學生示範」：檢視學生手機版答題介面。
- 右上角可切換中文／英文與音效；首頁也有「測試音效」按鈕。

## 加入碼如何使用

- 真正讓不同手機加入：教師與學生都要填入同一個 Cloudflare Worker URL（API Base）。教師建立線上課堂後，畫面會顯示 6 位數加入碼；學生輸入加入碼、暱稱與相同的 API Base 即可加入。
- 沒有 API Base 時，系統只會建立「離線演示加入碼」，不能讓其他裝置跨網路加入；此時請使用「先玩單機示範」。

## Cloudflare D1 部署

1. 建立 D1 database。
2. 執行 `schema.sql`。
   - 如果 D1 已用舊版 schema 建立，另執行一次 `migrate-language.sql`，讓課堂語言可以同步保存。
3. 將 `worker.js` 部署為 Cloudflare Worker，並將 D1 binding 名稱設為 `DB`。
4. 把 Worker URL 填入遊戲首頁的 `API Base`。
5. 將 `index.html` 部署到 Cloudflare Pages，或與 Worker 靜態檔案一起部署。

## 教學功能

- 8 題核心題庫，涵蓋匯率、外匯存底、GDP 與內需。
- 每位學生個人計分與排行榜。
- 教師切換中文／英文後，線上課堂的學生裝置會同步切換；語言狀態保存於 D1。
- 三階提示的第一、二層已內建於學生介面；解析在送出後顯示。
- Web Audio API 產生倒數、答對與答錯音效。
- 錯題知識點報告與 CSV 匯出。
- 外部插圖載入失敗時自動切換為內建 SVG，不會顯示破圖。

## 注意

本版本可離線完整演示；多裝置即時同步需要部署 `worker.js` 與 D1。正式課堂若要加入 AI 助教，請在 Worker 端代理 AI 請求，勿把 API key 放進 HTML。
